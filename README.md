# Biblioteca Digital UniFECAF — Design Web

Protótipo acadêmico responsivo desenvolvido com HTML5 e CSS3, alinhado às seções do protótipo enviado.

## Estrutura
- `index.html` — estrutura semântica e conteúdo
- `css/style.css` — identidade visual, componentes e media queries
- `assets/imagens/` — pasta para capturas e imagens locais

## Executar
Abra `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie um repositório público e envie todos os arquivos mantendo as pastas.
2. Vá em Settings → Pages.
3. Escolha Deploy from a branch, branch `main` e pasta `/(root)`.
4. Salve e copie a URL pública depois da publicação.

Os títulos do catálogo são fictícios e demonstrativos. Substitua por dados oficiais antes de qualquer uso institucional.
